# Claude Skills Marketplace

A curated marketplace of reusable Claude skills, packaged as Claude Code plugins. Use this repository to develop, package, distribute, and consume AI-powered skills for healthcare and other domains.

---

## 📝 About This Repository

**Claude Skills Marketplace** lets your team build and share specialized skills for Claude, as installable plugins. Each plugin is a set of one or more tightly related tasks—such as patient record management, data validation, or healthcare UI patterns. This repo makes it easy to author new skills, maintain a plugin catalog, and enable rapid skill sharing via GitHub and the Claude Marketplace.
