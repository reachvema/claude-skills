# Python Scaffold

When to use
- You are starting a new Python project and want a consistent layout.

Instructions
1. Create a standard Python project structure with directories: src/, tests/, docs/.
2. Create src/__init__.py to mark package root.
3. Add a minimal pyproject.toml with build-system requirements.
4. Add README.md, LICENSE (optional), and .gitignore entries for virtual environments and caches.
5. Add a sample tests/test_basic.py with a trivial test.
