# Hello Skill

## When to use
- The user asks for a demo or example of a skill.

## Instructions
1. Greet the user warmly.
2. Briefly explain that this skill lives in `plugins/example-skills/skills/hello-skill`.
3. Offer to help them create their own skill using `scripts/new-skill.sh`.
