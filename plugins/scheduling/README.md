# Scheduling Skills Plugin

A comprehensive plugin for DevOps, cloud deployment, and legacy modernization workflows.

## Skills Included

### 1. Discover Legacy Codebase
Analyze and understand legacy codebases to identify structure, dependencies, and architectural patterns.

### 2. Uncover Tech Debt and Suggest Coding Patterns
Identify technical debt, code smells, and suggest modern coding patterns and best practices.

### 3. Containerize Solution
Package applications into Docker containers for consistent deployment across environments.

### 4. Deploy to Azure Cloud using ACA
Deploy containerized applications to Azure Container Apps for scalable cloud hosting.

### 5. Debug Deployment Issues with Claude into Azure
Troubleshoot and resolve common Azure deployment issues using systematic debugging approaches.

### 6. Develop API on C# .NET
Build robust, scalable RESTful APIs using C# and ASP.NET Core.

## Installation

To use this plugin with Claude, add it to your Claude plugins directory.

## Usage

Each skill provides structured guidance for:
- Key objectives and actions
- Tools and techniques
- Best practices
- Expected outputs
