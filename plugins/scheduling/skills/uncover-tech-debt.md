# Uncover Tech Debt and Suggest Coding Patterns

## Objective
Identify technical debt, code smells, and suggest modern coding patterns and best practices.

## Key Actions
- Detect code duplication and redundancy
- Identify outdated dependencies and libraries
- Find poorly structured or tightly coupled code
- Spot missing error handling and validation
- Locate hard-coded values and magic numbers
- Identify missing tests or low test coverage
- Detect security vulnerabilities and anti-patterns

## Suggested Improvements
- Apply SOLID principles
- Implement design patterns (Factory, Strategy, Repository, etc.)
- Introduce dependency injection
- Add comprehensive error handling
- Implement logging and monitoring
- Suggest refactoring opportunities
- Recommend modern language features

## Tools & Techniques
- Static code analysis
- Complexity metrics (cyclomatic complexity)
- Linting and code quality tools
- Security scanning

## Outputs
- Tech debt inventory with severity ratings
- Prioritized refactoring recommendations
- Code pattern suggestions
- Modernization roadmap
