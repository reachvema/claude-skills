# Discover Legacy Codebase

## Objective
Analyze and understand legacy codebases to identify structure, dependencies, and architectural patterns.

## Key Actions
- Map directory structure and file organization
- Identify main entry points and application flow
- Document technology stack and frameworks used
- Catalog external dependencies and libraries
- Find configuration files and environment setup
- Identify database schemas and data models
- Locate documentation and inline comments

## Tools & Techniques
- Code search and pattern matching
- Dependency analysis
- Call graph generation
- File and folder structure visualization

## Outputs
- Codebase map with key components
- Technology stack summary
- Dependency tree
- Architecture overview
