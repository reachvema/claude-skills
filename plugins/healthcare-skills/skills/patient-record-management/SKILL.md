# Patient Record Management

## When to use
- When the user needs to view, update, or create patient medical records.
- When data validation and audit logging for records are required.

## Instructions
1. Validate incoming patient data for required fields and formats.
2. Perform CRUD operations on the patient record database.
3. Log access and changes securely to comply with healthcare regulations.
4. Return confirmation or error details to the user.
