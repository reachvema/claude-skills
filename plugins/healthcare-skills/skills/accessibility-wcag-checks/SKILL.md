# Accessibility WCAG Checks

## When to use
- Reviewing UI components, forms, and flows for accessibility.
- Before releases to ensure inclusive patient and provider experiences.

## Instructions
1. Verify color contrast ratios, focus visibility, and keyboard navigation for all controls.
2. Ensure proper ARIA roles, labels, landmarks, and alt text for non-text content.
3. Provide captions/transcripts for media and validate error messaging with programmatic associations.
4. Test with screen readers and document known issues with remediation guidance.
