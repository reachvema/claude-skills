# Health Data Visualization

## When to use
- When displaying patient history, vitals, or analytics dashboards.
- Generating charts or graphs for user interpretation.

## Instructions
1. Aggregate patient data from relevant sources.
2. Choose appropriate chart types (line, bar, pie).
3. Render visualizations with clear legends and labels.
4. Provide options to filter date ranges or data types.
