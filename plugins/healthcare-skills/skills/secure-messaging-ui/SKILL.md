# Secure Messaging UI

## When to use
- Building patient or provider portals with messaging features.
- Supporting attachments and read receipts with clear status indicators.

## Instructions
1. Provide inbox/outbox with message threading and search.
2. Support secure file attachments with type/size validation and malware scanning upstream.
3. Show read status, timestamps, and escalation indicators for urgent messages.
4. Expose clear compose, reply, and triage flows with helpful empty-states.
