# Telehealth Session UI

## When to use
- Implementing or enhancing virtual visit experiences.
- Handling connectivity issues and pre-call setup.

## Instructions
1. Provide pre-visit checks (camera, microphone, bandwidth) and capture user consent.
2. Show appointment details with a clear join button and countdown.
3. Offer controls for mute, camera toggle, background blur, and screen sharing as applicable.
4. Implement graceful reconnection, error messaging, and end-of-visit summaries or surveys.
