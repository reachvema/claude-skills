# Claims Processing

## When to use
- Receiving or validating medical claims.
- Determining coverage, member eligibility, and applying plan rules.

## Instructions
1. Validate claim structure and required fields before processing.
2. Verify member eligibility and provider information.
3. Apply benefits, allowed amounts, deductibles, and copays per plan rules.
4. Produce a clear adjudication summary with line-level outcomes and reasons.
