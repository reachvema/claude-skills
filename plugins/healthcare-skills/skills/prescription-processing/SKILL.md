# Prescription Processing

## When to use
- When a provider submits a new or updated prescription.
- Checking for drug interactions, allergies, or errors in prescriptions.

## Instructions
1. Validate prescription details for completeness and correctness.
2. Cross-check drug interactions and patient allergy information.
3. Notify providers of any issues or approvals.
4. Record prescription status and fulfillment updates.
