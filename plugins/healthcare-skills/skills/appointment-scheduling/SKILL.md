# Appointment Scheduling

## When to use
- User requests to book, reschedule or cancel healthcare appointments.
- When checking provider availability or sending reminders.

## Instructions
1. Check provider calendars for availability.
2. Handle appointment requests, updates, and cancellations.
3. Notify patients and providers via preferred channels.
4. Confirm appointments or report conflicts/errors clearly.
