# Patient Intake Forms UI

## When to use
- Designing or updating intake/onboarding forms.
- Ensuring validation, responsiveness, and save/resume functionality.

## Instructions
1. Structure forms into logical, short steps with progress indicators and autosave.
2. Validate inputs (addresses, insurance details, medical history) with inline feedback.
3. Support accessibility (labels, ARIA, keyboard navigation) and responsive layouts.
4. Provide review-and-submit with printable confirmation and error summaries.
