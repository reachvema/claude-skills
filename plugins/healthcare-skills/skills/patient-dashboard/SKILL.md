# Patient Dashboard

## When to use
- Display patient health info summaries and upcoming appointments.
- When users need an interface to view alerts or recent test results.

## Instructions
1. Fetch patient data and stats securely.
2. Render health metrics, graphs, and appointment lists clearly.
3. Provide actionable alerts or messages.
4. Ensure UI components are responsive and accessible.
