# Appointment Booking UI

## When to use
- User interacts with the appointment booking or rescheduling screens.
- When validating user input and providing tooltips or error messages.

## Instructions
1. Guide users step-by-step through available slots.
2. Validate input fields such as date, time, and reason.
3. Provide contextual hints or error feedback.
4. Confirm booking success and show next steps.
